# Membangun Tim Melalui Perspektif Kepribadian (16 Tipologi)

Interactive Full HD (1920x1080) Bento Grid Presentation Deck — Dirancang untuk DAPENDA Executive Gathering & PT. PP (Persero) Tbk.

🌐 **Live Demo (GitHub Pages):** [https://notsyam.github.io/slide-mbti/](https://notsyam.github.io/slide-mbti/)

---

## 🎯 Gambaran Proyek
Slide deck interaktif modern berbasis web yang mengadaptasi 39 halaman materi presentasi *Building Team Using Personality Perspective* ke dalam format **22 Slide Bento Grid Full HD (1920x1080)**.

Materi berfokus pada pengenalan 16 tipe kepribadian (Carl Jung & Myers-Briggs) dalam konteks kepemimpinan, pemetaan kekuatan alami (*natural strengths*), titik buta (*blindspots*), serta formula mitra ideal (*synergy partner*) untuk mencegah friksi antarkaryawan dan memperkuat kolaborasi organisasi.

---

## ✨ Fitur & Keunggulan Desain
- **Bento Grid Layout:** Struktur modular, teratur, dan memiliki *negative space* yang proporsional sehingga presentasi terasa lapang dan berkelas eksekutif.
- **Hierarki Tipografi Khusus Audiens 45+:** Menggunakan font **Plus Jakarta Sans** dengan ukuran yang diperbesar (Body 14–18px, Heading 28–48px) dan rasio kontras tinggi sesuai standar aksesibilitas WCAG.
- **Portret Tokoh dengan Linear Gradient Masking:** Foto tokoh 16 tipologi (termasuk potret tokoh publik Indonesia dan global) memiliki transisi gradien halus (`-webkit-mask-image`) di mana bagian wajah terlihat tegas dan jelas sementara bagian torso menyatu dengan latar belakang kartu.
- **Penjajaran Ikon & Teks Presisi:** Menggunakan 2-column grid layout khusus sehingga setiap ikon Google Material Symbols tegak lurus dan sejajar secara matematis dengan baris pertama teks.
- **Floating Glass HUD Navigation:** Navigasi bergaya kapsul melayang di sudut kanan bawah, memaksimalkan tinggi kanvas 1080px tanpa terpotong footer statis.
- **Self-Contained & Fast Loading:** Seluruh aset gambar dan logo PT. PP di-embed langsung (Base64) di dalam file HTML sehingga dapat berjalan secara offline maupun online tanpa kendala link rusak.

## ⌨️ Kontrol & Pintasan Keyboard
| Tombol / Tombol Pintas | Aksi |
| :--- | :--- |
| **Panah Kanan** (`→`) / **Spasi** / **PageDown** | Pindah ke Slide Berikutnya |
| **Panah Kiri** (`←`) / **PageUp** | Kembali ke Slide Sebelumnya |
| **F** | Toggle Layar Penuh (*Fullscreen Mode*) |
| **G** | Buka Indeks Semua Slide (*Slide Grid Modal*) |
| **Home** | Langsung ke Slide Pertama (Cover) |
| **End** | Langsung ke Slide Terakhir (Penutup) |
| **Esc** | Menutup Menu / Modal Slide Grid |

## 🚀 Mengaktifkan GitHub Pages
Jika halaman GitHub Pages belum aktif secara otomatis, ikuti langkah berikut:
1. Buka repositori di GitHub: [https://github.com/NotSyam/slide-mbti](https://github.com/NotSyam/slide-mbti)
2. Masuk ke tab **Settings** > **Pages** (di sidebar kiri).
3. Di bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
4. Di bagian **Branch**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu sekitar 1–2 menit, web presentasi Anda akan live di:
   👉 **https://notsyam.github.io/slide-mbti/**
